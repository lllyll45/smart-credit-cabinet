# Smart Credit Cabinet — запуск проекта

Инструкция для локального запуска backend (без Docker и с Docker).

## 1. Требования

- Git
- Python 3.13
- PostgreSQL 18 (для локального запуска без Docker)
- Docker Desktop (для запуска с Docker)
- PowerShell (Windows)
