# Smart Credit Cabinet — полный план проекта и текущий прогресс

Проект — веб-приложение для подбора и сравнения кредитных предложений. Пользователь регистрируется, заполняет данные о себе и желаемом кредите, создаёт заявку и получает возможность сравнить подходящие предложения.

Команда: 3 человека — 2 разработчика backend и 1 разработчик frontend. Разработка идёт в репозитории `smart-credit-cabinet`. Ниже разделю то, что уже сделано, и то, что ещё предстоит.

## 1. Что уже сделано

1. Создан каркас проекта

Подготовлены основные папки `backend/`, `frontend/`, `docs/`, `tests/`, а также `.gitignore`, `docker-compose.yml` и `README.md` в структуре проекта.

2. Настроен backend

Используется FastAPI и Python. Создано виртуальное окружение `.venv`, приложение запускается локально и доступно по адресу `http://127.0.0.1:8000`.

3. Подключена PostgreSQL

Настроены подключение к базе данных и конфигурация приложения. Локальный файл `.env` содержит настройки окружения и секреты, поэтому его нельзя добавлять в Git.

4. Настроены модели пользователей и заявок

Созданы модели `User` и `CreditApplication`, связь между ними и основные поля заявки: сумма, срок, цель, доход, занятость, статус, комментарий и даты создания и изменения.

5. Реализована авторизация

Добавлены регистрация, вход с паролем, хеширование пароля, JWT-токены и получение текущего пользователя. Авторизация проверена через Swagger и покрыта тестами.

6. Настроены миграции Alembic

Миграция пользователей уже существовала. Создана миграция `d2eefc340c25` для таблицы `credit_applications`. После её применения таблица стала доступна приложению.

7. Реализован и проверен API кредитных заявок

Проверены создание, получение списка, получение отдельной заявки, редактирование и отправка заявки. Все эти запросы завершились успешными HTTP-ответами и покрыты тестами.

8. Реализован каталог кредитных продуктов

Создана модель `CreditProduct` с полями: название, банк, процентная ставка, диапазон суммы, диапазон срока, комиссии, дополнительные условия, активность. Создана миграция `61ffaf4ab915`. Добавлены API `GET /api/v1/products` и `GET /api/v1/products/{product_id}`. Подготовлены 3 демонстрационных продукта (`scripts/seed_products.py`).

9. Реализован кредитный калькулятор и сравнение

Калькулятор рассчитывает аннуитетный ежемесячный платёж, общую сумму выплат и переплату. Комиссии (`commission_rate` или `commission_amount`) учитываются в `total_payment` и `overpayment`. Добавлены API `POST /api/v1/calculator/calculate` и `POST /api/v1/calculator/compare`. Сравнение фильтрует продукты по сумме и сроку и сортирует по `total_payment`. В ответе есть поле `disclaimer` с предупреждением, что расчёт предварительный.

10. Добавлена демонстрационная логика одобрения и отказа

После отправки заявки backend рассчитывает платёж и сравнивает его с доходом пользователя. Если платёж не превышает 40% дохода, заявка одобряется; иначе отклоняется. Это демонстрационное правило, не настоящий банковский скоринг.

11. Написаны автоматические тесты

Покрыто 59 тестов: auth (10), applications (11), processing (4), calculator (7), calculator API (9), calculator edge cases (9), products (4), security (5). Все тесты проходят.

## 2. Что сейчас умеет backend

Все перечисленные эндпоинты проверены по логам сервера и покрыты тестами.

| Метод и эндпоинт | Назначение | Результат |
|---|---|---|
| `POST /api/v1/auth/register` | Регистрация пользователя | 201 Created |
| `POST /api/v1/auth/login` | Авторизация | 200 OK |
| `GET /api/v1/auth/me` | Данные текущего пользователя | 200 OK |
| `POST /api/v1/applications` | Создание заявки | 201 Created |
| `GET /api/v1/applications` | Список своих заявок | 200 OK |
| `GET /api/v1/applications/{id}` | Получение заявки | 200 OK |
| `PATCH /api/v1/applications/{id}` | Редактирование заявки | 200 OK |
| `POST /api/v1/applications/{id}/submit` | Отправка заявки | 200 OK |
| `GET /api/v1/products` | Список активных продуктов | 200 OK |
| `GET /api/v1/products/{product_id}` | Детали продукта | 200 OK |
| `POST /api/v1/calculator/calculate` | Расчёт по продукту | 200 OK |
| `POST /api/v1/calculator/compare` | Сравнение подходящих продуктов | 200 OK |

Документация API доступна через Swagger: `http://127.0.0.1:8000/docs`.

Важно: успешные ответы подтверждают работоспособность запросов, но не означают, что проверены все ограничения доступа, ошибки валидации и бизнес-правила. Часть ограничений покрыта тестами (см. раздел 3, этап 5).
